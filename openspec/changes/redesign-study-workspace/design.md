# Design

## Context

`src/app/page.tsx` содержит лендинг и ориентиры 600 000 знаков и 500 терминов. `LoginForm` отправляет пользователя на `/account`, где `Workspace` показывает учебные назначения, профиль или управление по роли. `/library` и `/glossary` уже принимают `enrollmentId` и выводят раздельные сводки. `RootLayout` сейчас одинаков для гостя и кабинета. Основные спецификации OpenSpec ещё не заведены.

## Goals / Non-Goals

**Goals:** единый выбор учебного контекста и согласованная статистика на трёх страницах, общие доступные компоненты и темы.

**Non-Goals:** автоматический зачёт, изменение правил доступа, новая схема БД или переработка операций с материалами.

## Decisions

1. **Маршруты.** Защищённая главная остаётся на `/`. Гость перенаправляется на `/login`, успешный вход ведёт на `/`. Разделить гостевой каркас входа и восстановления пароля и рабочий каркас кабинета. Сохранить `/account` для профиля и управления, `/library` для «Источников» и `/glossary` для словаря. Сохранение прежних URL поддерживает закладки. Ссылки на бывший блок `/#goals` заменить контекстными пояснениями рядом с показателями.
2. **Назначение.** Использовать `enrollmentId` в URL как явный контекст. Если он отсутствует, автоматически выбирать только единственное доступное назначение, а при нескольких показывать выбор без предвыбранного студента. Выбор должен охватывать все доступные назначения, включая записи за пределами первой страницы существующей выдачи `/account`. Проверять идентификатор на сервере, используя правила `authorizeEnrollment`, не полагаясь на клиентское меню. Для гостя, пользователя без доступа и сбоя сервиса показывать разные состояния, чтобы избежать циклов перенаправления и ложных нулей. Администратору с главной дать переход в управление.
3. **Сводки.** Выделить переиспользуемые серверные запросы агрегатов из сервисов литературы и словаря. Вычислять их по назначению после проверки доступа, независимо от запросов списков. Для источников показать число записей и фактический заявленный объём, для словаря — все термины и черновики, на полосе — термины с переводом. Сохранить точность суммарного объёма и ограничивать только ширину полосы. Текст рядом с полосами объясняет, что цели относятся к зачёту и полосы показывают подготовленные данные. Полосы подходят для сравнения с фиксированными ориентирами без введения временных рядов или библиотеки диаграмм.
4. **Добавление источника.** Переиспользовать `LiteratureForm` и существующий компонент диалога. Модальное окно оставляет пользователя в списке, где сразу виден результат. Предусмотреть прокрутку формы на узких экранах, управление фокусом, Escape и возврат фокуса к кнопке. Во время загрузки PDF и сохранения исключить повторную отправку, при ошибке сохранить заполненное, после успеха закрыть диалог и обновить список и сводку.
5. **Оформление.** Ориентиры — [официальный сайт Президентской академии](https://www.ranepa.ru/index_.php) и [руководство по фирменному стилю, раздел 1.2](https://it.ranepa.ru/upload/iblock/bbf/bbf9fcc258b510f1cb342778e82692e0.pdf#page=24). Для Engxam использовать выразительные заголовки, простую сетку и красный акцент с опорой на опубликованный RGB 146/26/29 (`#921a1d`). В светлой теме использовать светлые поверхности и тёмный текст, в тёмной — графитовые поверхности и более светлый красный для фокуса и важных элементов. Использовать читаемую кириллическую гарнитуру и сохранить собственное название Engxam. Фон, текст, границы, состояния и полосы определять общими CSS-переменными.
6. **Тема.** Сохранять явное предпочтение в браузере, использовать `prefers-color-scheme` при его отсутствии и применять тему до первой отрисовки при перезагрузке. Разместить переключатель в обоих каркасах. Такой выбор работает на форме входа и после выхода без привязки к аккаунту.

## Risks / Trade-offs

- Полосу можно принять за официальный зачёт → указывать единицу, состав показателя и пояснение рядом с числом.
- Сохранённая ссылка может потерять доступ после переназначения преподавателя → заново проверять права на сервере и давать выход на главную без раскрытия содержимого.
- Длинная форма в диалоге → проверить прокрутку с клавиатуры и на мобильном экране.

## Migration Plan

Развернуть маршруты, каркасы и сводки вместе. Миграций данных нет. Ранее сохранённые ссылки на список и профиль остаются рабочими. При откате возвращается прежний маршрут после входа.
