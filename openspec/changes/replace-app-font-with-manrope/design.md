# Design

## Context

Корневой layout `src/app/layout.tsx` обслуживает гостевые и авторизованные страницы. В `src/app/globals.css` семейство `--font` задаёт шрифт `body`, а кнопки и поля наследуют его через `font: inherit`. Планируемое обновление учебного пространства затрагивает глобальные стили, поэтому при объединении изменений нужно сохранить настройку шрифта из этого предложения.

## Goals / Non-Goals

**Goals**

- Подключить Manrope через Google Fonts один раз для всего дерева маршрутов.
- Сохранить существующие размеры текста, межстрочный интервал и наследование в формах.

**Non-Goals**

- Типографика скачиваемых документов и содержимого PDF.

## Decisions

- Добавить в `head` корневого layout ссылки для предварительного соединения и загрузки вариативного Manrope с весами 200–800. Файлы шрифта загружает браузер при посещении страницы.
- Указать `"Manrope", Arial, "Segoe UI", sans-serif` в токене `--font`. Параметр `display=swap` позволяет показать текст резервным шрифтом во время загрузки Manrope.

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@200..800&display=swap" rel="stylesheet">
```

## Risks / Trade-offs

- При недоступности Google Fonts браузер отобразит текст системным шрифтом из резервного стека.
- Другие метрики Manrope могут изменить переносы в длинных русских подписях и узких элементах. Проверить форму входа и учебный экран на мобильной и настольной ширине.
- Реализации этого изменения и обновления учебного пространства могут затронуть один CSS-токен. При объединении проверить итоговое объявление `--font`.

## Migration Plan

Для отката достаточно развернуть предыдущую версию приложения.
