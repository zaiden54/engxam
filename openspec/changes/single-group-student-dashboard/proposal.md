# Proposal

## Why

Ограничение на уровне учебного потока допускает несколько назначений для одного студента, а преподаватель ищет подопечных в общем списке назначений. Студенту нужен прямой доступ к своему прогрессу, а преподавателю — навигация по учебным группам.

## What Changes

- Студент может состоять максимум в одной текущей группе английского на платформе. После входа главная автоматически показывает его группу и личную статистику по источникам и словарю.
- Преподаватель видит список закреплённых за ним групп и открывает список студентов выбранной группы. Например, у одного преподавателя могут быть две группы по системному анализу и одна по экономике.
- Администратор закрепляет преподавателя за группой и назначает студентов в группы. Перевод студента сохраняет его текущие материалы и прогресс.
- **BREAKING** Назначение преподавателя переносится с записи студента на группу. Административные команды и формы меняются вместе. Существующие ссылки по `enrollmentId` проверяются по актуальным правам доступа.

## Capabilities

### New Capabilities

- `english-group-membership` — состав групп, закрепление преподавателя и единственное текущее назначение студента.

### Modified Capabilities

- `study-workspace` — персональная главная студента и переход преподавателя от группы к студенту.

## Impact

Затронуты схема и миграции PostgreSQL, административный кабинет и API управления обучением, главная и навигация, проверки доступа к материалам и тесты учебных сценариев. Текущие идентификаторы назначений и формулы прогресса сохраняются.
