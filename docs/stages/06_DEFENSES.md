# Этап 06. Защиты и пакетное принятие

Зависимости: 03, 04, 05. Результат: преподаватель одним действием признаёт материал пригодным и начисляет объём; новые слова принимает группами.

## Задачи: пакет и литература

- [ ] Создать Defense, DefenseItem, LiteratureDecision, DefenseTerm, TermDecision и ограничения ревизий/владения/диапазонов.
- [ ] Реализовать черновик, отправку снимка, отзыв до начала проверки, review_started_at и возврат на доработку; исключить гонку отзыва с проверкой.
- [ ] Разрешить пакет из нескольких работ и/или только терминов; глава и включительный диапазон физических страниц обязательны для фрагмента.
- [ ] Реализовать принятие двух статей из трёх и разделение диапазона одной главы на принятые/отклонённые части.
- [ ] Сохранять заявленные и подтверждённые объёмы отдельно; знак считается с пробелом, без сносок/библиографии. Не вычислять объём пропорционально страницам.
- [ ] Внедрить exclusion constraint действующих зачётов и проверки покрытия диапазонов; повторная защита отклонённого разрешена, принятых страниц — запрещена.
- [ ] Реализовать отдельное сохранение результатов литературы/терминов, финализацию только полностью оценённого пакета, явный отзыв ошибочных решений и аудит.

## Задачи: словарь без сотен кликов

- [ ] Показывать новые/исправленные отправленные термины конкретной недели; принятые раньше скрыты из списка неоценённых.
- [ ] Добавить «Принять все N терминов пакета» без выбора каждой строки.
- [ ] Добавить исключения «На доработку», общую причину для группы и индивидуальные комментарии; итог «Принять N, вернуть M».
- [ ] Различать весь пакет и видимую страницу; фильтрация не меняет неявно область массового действия.
- [ ] Сохранять отдельное решение на термин одним атомарным запросом; сервер проверяет IDs, ревизии, полномочия и version. Повтор запроса не удваивает зачёт.
- [ ] Создать мобильную панель массовых действий с количеством, без перекрытия списка/клавиатуры и обязательного открытия каждого слова.

## Проверки и приёмка

- [ ] 500 корректных терминов одного пакета принимаются одним массовым действием; для двух исключений достаточно отметить только эти два слова.
- [ ] При пагинации действие явно принимает весь названный пакет; чужой ID/устаревшая версия откатывает всю команду.
- [ ] Параллельное принятие пересекающихся страниц даёт один зачёт; разные главы не обходят ограничение.
- [ ] Новая попытка хранит историю старой; отмена записи/занятия не удаляет уже сделанные зачёты.
- [ ] Замена PDF после зачёта запрещена, правка принятого термина требует новой проверки.
- [ ] Частичный зачёт и массовая проверка проходят E2E на мобильном и desktop viewport.
