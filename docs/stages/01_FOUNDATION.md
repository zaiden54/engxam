Зависимости: нет. Результат: собирающееся приложение с проверенной инфраструктурой и базовыми компонентами для ПК и телефона.

## Задачи

- [x] Зафиксировать совместимые стабильные версии Next.js, TypeScript, Better Auth, Drizzle и зависимостей, lockfile и команды разработки.
- [x] Создать App Router и структуру модулей из архитектуры, server-only границы, валидацию переменных окружения и пример env без секретов.
- [x] Подключить тестовую PostgreSQL, механизм миграций и транзакций; проверить блокировки и btree_gist на выбранном окружении.
- [x] Проверить Neon Object Storage: private access, временные URL, CORS, Range, фиксацию неизменяемого объекта. Записать результат прототипа. При несовместимости вынести конкретную замену на согласование.
- [x] Настроить typecheck, lint, build, unit/integration/E2E инструменты и CI; тестовая БД изолирована от production.
- [x] Создать дизайн-основу: типографика, цвета, отступы, кнопки, поля, ошибки, диалоги, уведомления, skeleton, карточки и таблицы.
- [x] Реализовать адаптивный layout, desktop/sidebar и mobile/navigation, страницу входа как каркас и демонстрационные состояния интерфейса.
- [x] Настроить request_id, безопасные ошибки, логирование без секретов и базовую обработку сетевых сбоев.

- [x] Локальная установка запускает приложение; build и проверки проходят. Workflow CI подготовлен; удалённый запуск GitHub Actions пока не выполнялся.
- [x] Тестовая транзакция откатывается, ограничения диапазонов работают; инфраструктурные возможности подтверждены фактически.
