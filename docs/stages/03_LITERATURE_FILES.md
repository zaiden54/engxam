# Этап 03. Библиотека и приватные PDF

Зависимость: 02. Результат: студент ведёт библиотеку, преподаватель просматривает разрешённые материалы; загрузка не начисляет зачёт.

## Задачи

- [x] Создать Literature, LiteratureRevision и FileAsset с FK владения и принадлежности текущей ревизии.
- [x] Реализовать метаданные статьи/монографии/сборника, библиографические страницы и физические номера PDF, заявленные знаки с пробелами и необязательные слова.
- [x] Реализовать прямую загрузку во временный ключ, серверную проверку размера/сигнатуры/страниц/хеша и неизменяемую фиксацию конечного объекта.
- [x] Реализовать uploading/ready/failed/deleting/deleted и повторяемую finalizeUpload, компенсацию рассинхронизации БД/хранилища.
- [x] Добавить приватный просмотр и скачивание после проверки прав; короткие URL, Range, ограничение кеширования.
- [x] Реализовать DOI/hash проверки дублей, предупреждение по метаданным, версионность, архивирование и ограничения замены PDF.
- [x] Создать библиотеку с поиском, фильтрами, пагинацией и мобильными карточками; PDF-viewer со скачиванием и обработкой ошибок.
- [x] Реализовать безопасную очистку бесхозных загрузок, исключающую используемые исторические файлы.

## Проверки и приёмка

- [x] Чужой file_id, storage_key или literature_id не позволяет получить/привязать чужой файл.
- [x] Ошибка сети не создаёт ready; повтор завершения не создаёт дубль; старое разрешение загрузки не меняет конечный объект.
- [x] Некорректный и превышающий лимит PDF отклоняется; обычный PDF загружается с телефона и открывается на ПК.
- [x] Архивирование и редактирование сохраняют ревизии; показанный объём библиотеки не называется зачтённым.

Контроль замены PDF после появления решений окончательно проверяется вместе с этапом 06. Автоматический подсчёт знаков из PDF не реализуется.


Статус: реализован и проверен на БД, хранилище, Chromium и мобильном WebKit. Миграции применены к production. Подробности и эксплуатационные ограничения — в [отчёте](03_REPORT.md).
